Self-Hosted Credential Vault

Description

A cryptographically secure, self-hosted web-based password management application designed to centralize access across Windows and Android systems. Uses no cloud services. Employs proper techniques according to defense-in-depth, zero-knowledge, and network isolation methodologies.

Features

Zero-Knowledge Cryptography

Implements a system of client-server encryption via PHP's OpenSSL implementation of the AES-256-GCM standard. Securely generated IVs and auth tags stored as binary data in MySQL to prevent improper handling or tampering.

Custom-PKI

Configured custom X.509 CAs to establish authenticated HTTPS connections between client devices (Desktop/Android Chrome) and server device (Apache HTTPS).

Secure Database Interaction

Secured MySQL database interactions by using fine-tuned stored procedures for all commands to prevent injection attacks and limit general attack surface.
