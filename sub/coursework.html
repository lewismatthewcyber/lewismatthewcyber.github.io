Computer Virtualization Technology - CET 2544C (Valencia)

Course Description

This course is designed to provide students with a working knowledge of VMware Workstation as a leading virtualization product. In addition to learning how to install and use VMware Workstation, students will learn how to apply virtualization technology to set up virtual networks, provide for disaster recovery, create high-availability solutions with clustering, improve security and performance, and use management software to administer multiple virtual machines.

Relevant Topics, Skills, and Technologies

  • Virtual Networks
  • HA-solutions
  • VMWare Workstation, Windows, Linux

Ethical Hacking - CET 2892C (Valencia)

Course Description

The overarching objective of this course is to arm the student with the practical knowledge necessary to integrate the defense-in-depth strategy, as detailed by the National Security Agency (NSA), in deploying, hardening, monitoring, and defending critical information infrastructure. The National Security Agency (NSA) and the Committee on National Security Systems (CNSS) has recognized this course for meeting the CNSS 4013 training standard.

Relevant Topics, Skills, and Technologies

  • Passive and Active Reconnaissance Techniques
  • Cryptographic Systems
  • Steganographic Techniques
  • Vulnerability Assessment
  • Target Discovery and Enumeration
  • Parrot OS/Kali Linux, Nessus, VMWare

Related Projects

  • Final Project - Simulated Penetration Test
    • Performed a simulated penetration test on a virtualized network consisting of 2 client machines (Windows 7 and Windows 10) and two server machines (Windows Server 2008 and Server 2019).
    • Penetration testing included all formal steps, starting with system/network discovery and ending with documention.
    • Final documentation totalled 67 pages,including an executive summary, a comprehensive review of the attack narrative, security recommendations, risk-ratings, and an appendix.
